# WoT Sound Notifier
 
**Целевая IDE:** Visual Studio Code (Code-OSS)

## Описание

**WoT Sound Notifier** — расширение для Visual Studio Code, которое озвучивает ключевые события работы в редакторе фразами из игры World of Tanks.

## Возможности

- **Озвучка запуска IDE:** воспроизведение приветственной фразы при старте VS Code (`onStartupFinished`).
- **Реакция на компиляцию и сборку в терминале:** отслеживание завершения команд компиляторов и сборщиков (`g++`, `gcc`, `clang++`, `make`, `cmake`, `javac`, `rustc`, `cargo`, `go`, `tsc`, `python`, `python3`):
  - код возврата `0` — воспроизведение фразы об успешной сборке;
  - ненулевой код возврата — воспроизведение фразы об ошибке.
- **Очередь воспроизведения (FIFO):** звуки проигрываются строго последовательно без наложения друг на друга.
- **Защита от повторов:** случайный выбор фразы из доступного пула без повторения предыдущего трека подряд.
- **Быстрое управление:** команда `WoT: Toggle Sound` в Command Palette (`Ctrl+Shift+P`) для включения и выключения озвучки.

## Структура проекта

- `extension.js` — точка входа, регистрация команд и подписка на события VS Code.
- `soundManager.js` — загрузка аудиофайлов, выбор случайной фразы без повторов и управление состоянием.
- `soundQueue.js` — реализация очереди воспроизведения (FIFO) и запуск системного аудиоплеера (`ffplay`).
- `sounds/` — директория с аудиофайлами (`startup/`, `success/`, `error/`).
- `docs/` — автоматически сгенерированная JSDoc-документация по коду.
